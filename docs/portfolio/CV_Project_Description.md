# CV Project Description

## SauceDemo QA Engineering Portfolio

Built a risk-based QA and test automation portfolio around the SauceDemo e-commerce sandbox using JavaScript and Playwright. Designed manual test strategy and traceability artifacts, modeled user-facing risks, documented reproducible defects, and developed a maintainable automation architecture using Page Object Model, custom fixtures, external test data, web-first assertions, and network interception. Planned CI execution and HTML reporting through GitHub Actions.

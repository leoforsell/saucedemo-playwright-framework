# Practice-placement strategy template

**Status: planned.** Discuss readiness and timing with the relevant support person before starting outreach.

- Target work: supervised manual QA, test design, reproducible defect reporting, and gradually test automation.
- Employer criteria: relevant testing tasks, a named supervisor, manageable scope, and an agreed feedback routine.
- Evidence to prepare: one completed case, one reviewable result, one technical decision, and a clear account of limitations.
- Week 16 target: research 8–12 employers and prepare 5–8 personalized messages if readiness and capacity allow. These are planning targets, not required quotas or sent-message counts.
- Keep names, addresses, correspondence, follow-up dates, and placement agreements in a private tracker. The existing CSV is an empty schema reference; do not populate it in this public repository.
- Public progress: record aggregate outcomes only when useful; never imply a reply, interview, or placement without evidence.
